# Artisan Mart Backend Development Preview Acceptance

This development branch is not the live storefront. Public checkout remains disabled until branded Supabase Auth email/redirect configuration and real Stripe signature-verified payment integration are complete.

The controlled preview tests guest cart continuity, Supabase-backed catalog, inventory availability, login redirection, fail-closed catalog errors, and desktop/mobile parity. Do not merge to main on build success alone; require real-browser acceptance evidence.
